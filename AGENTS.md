# AGENTS.md

## Общие правила

Работай только в рамках поставленной задачи.

Перед изменением кода:
- читай только файлы, непосредственно связанные с задачей;
- переходи по зависимостям только при необходимости;
- не сканируй весь репозиторий без причины;
- не делай несвязанный рефакторинг.

Предпочитай минимальное изменение, достаточное для решения задачи.

Не изменять `README.md` без явного запроса пользователя.
Не изменять `ROADMAP.md` без явного запроса пользователя.

## Python

Сохраняй существующий стиль проекта.

Не добавляй новые зависимости без необходимости.

Сохраняй типизацию.

Не подавляй ошибки линтера и типизации без обоснованной причины.

`WIKI_TOKEN` берётся только из переменной окружения.

## Тесты

Сначала запускай тесты, непосредственно относящиеся к изменённому коду.

Полный набор тестов запускай только если изменение потенциально влияет
на несколько компонентов или это явно требуется задачей.

## Завершение задачи

Кратко сообщи:
- какие файлы изменены;
- что сделано;
- какие тесты запускались;
- остались ли проблемы.
